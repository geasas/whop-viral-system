# GLM Agent — ملف التعليمات التشغيلية (المهمة الكاملة)

> هذا الملف لتشغيل المهمة على GLM (وضع الأيجنت). اقرأه كاملاً قبل أي خطوة.
> ⚠️ **لا تضع أي باسورد أو حسابات داخل هذا الملف** — تُدخل في محادثة GLM مباشرة أو في مكان تأمين منفصل، وتُغيّر بعد التنفيذ.

---

## 1) الهدف النهائي

نظام أتوماتيكي يومي:
1. يدخل Whop ويكشف حملات الربح المتاحة (Content Rewards / حملات Clipping المدعومة رسمياً).
2. يختار أعلى حملة ربح متوافقة مع المحتوى المتاح.
3. يحمّل الفيديوهات الخام المصدر (مصرَّح بها أو مرخّصة).
4. يعدّلها بمونتاج AI (Retention Editing) حسب مواصفات الماسترز المرفقة.
5. ينشر يومياً على انستغرام + تيك توك (حسابات المستخدم).
6. يتابع أداء الفيديوهات ويحسّن الهوك شهرياً.

---

## 2) القواعد الصارمة (السلامة والحلال)

- 📌 **لا تخالف شروط Whop / TikTok / Instagram.** تسجيل الدخول المباشر الأتوماتيكي من جديد الجهاز = خطر حظر. الجأ للطرق القانونية:
  - TikTok: استخدم Content Posting API (tokens رسمية) لا تسجيل دخول الباسورد يومياً.
  - Instagram: استخدم Content Publishing API / Graph API أو Meta Business Suite.
  - Whop: جرّب أنسب دور وصول (صاحب محتوى/بائع) بدون مشاركة كاملة للحساب المصرفي؛ لا تغيّر إعدادات payout أبداً.
- 📌 **الحلال:** لا محتوى محرّم، لا إيحاء، موسيقى مباحة فقط، لا ربا/غرر في التسعير — التسعير واضح والمحتوى يُسلَّم فعلية.
- 📌 **حقوق المصدر:** لا تقصّ فيديوهات محمية بلا إذن. الأولوية لمصادر مرخّصة أو برامج Whop الرسمية (مثل Content Rewards التي تفوّض القص). أي قصّ خارج ذلك = إعادة استخدام إبداعية جوهرية (تحليل/ترجمة/تعليق) مع احترام شروط المنصة.

## 4) المراحل التنفيذية

### المرحلة 1 — إعداد الأصول (يوم واحد)
1. أنشئ حساب بائع Whop (مكتمل KYC) وصفحة عضوية/متحف (Whop AI يبنيه بسرعة).
2. فعّل **Whop Content Rewards** من لوحة البائع (هذه أهم خطوة لبدء الربح بلا متابعين).
3. جهّز حسابي إنستغرام وتيك توك (يفضّل: احسب ثانوي جديد للمختبرات أولاً).
4. ربط أداة نشر أتوماتيكي (Postiz / Ayrshare / Meta Graph API + TikTok API).
5. جهّز أداة قص AI (Opus Clip / Vizard / AutoShorts) + ترجمة (Submagic) + مونتاج.

### المرحلة 2 — اختيار الحملة
- قارن حملات Whop حسب: **عائد القطعة، شروط القص، حجم الطلب، إمكانية التنفيذ اليومي**.
- اختر الحملة الأعلى ربحاً التي يمكن تسليمها يومياً بجودة 5/6 على Retention Scorecard.

### المرحلة 3 — سير العمل اليومي (2-3 ساعات → مؤتمت)
1. جلب 3-5 مقاطع خام من المصادر المصرّح بها.
2. قص ذكي تلقائي + ترجمة + B-Roll + Beat Sync.
3. تحقق من **Retention Scorecard (6 بنود)**: لا تنشر أقل من 5/6.
4. جدولة النشر في ذروة النشاط (عبر API، لا تسجيل دخول يدوي).
5. تسجيل التحليل: View Rate، Retention@30s، Share Rate.

### المرحلة 4 — أسبوعي
- تحديث محتوى العضوية في Whop (قيمة مستمرة) + إطلاق داخلي بسيط (Backend Ascension).
- تحليل أفضل هُوك لكل فكرة ناجحة، وتحديث أعمدة المحتوى.
