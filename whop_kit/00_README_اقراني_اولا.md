## قواعد صارمة قبل البدء
1. **لا تسجّل دخول يومي بالباسورد** على تيك توك/انستغرام من متصفح AI — استخدم API رسمية (النشر عبر جدولة/توكنز) لتجنّب حظر الحسابات.
2. **لا تلمس إعدادات payout في Whop أبداً** — ولا تعطِ باسورد الحساب المالي الحقيقي لأداة خارجية.
3. الحلال: محتوى مباح فقط، موسيقى مباحة، تسعير واضح، قيمة تُسلَّم فعلياً.
4. حقوق القص: الأولوية لمصادر مرخّصة/برامج Whop الرسمية (Content Rewards)؛ أي قصّ خارج ذلك = إعادة استخدام إبداعية جوهرية مع احترام شروط المنصة.
5. نفّذ القاعدة: لا تنشر أي فيديو أقل من 5/6 على Retention Scorecard (في الملف 01).
6. بعد أول يوم تشغيل: **غيّر كل الباسوردات**.

## لمن الاستخدام
عملية أتوماتيكية يومية: كشف حملات Whop → اختيار الأعلى ربحاً → جلب الفيديوهات المصرّح بها → مونتاج AI (بسكيلز الوصفة) → نشر يومي → قراءة التحليلات وتحسين الهوك.
